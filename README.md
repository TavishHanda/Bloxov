# Bloxov

A blocky voxel extraction shooter. Loot weird stuff, get attached to it, try to make it out alive.

Design doc: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)

## Status: 0.7.7 (multiplayer update)

The current version and every change are in [`CHANGELOG.md`](CHANGELOG.md).

Gear up in the hideout, drop into a raid, loot crates/lockers/safes and dead scavs and Raiders, and get to an open
extract before the timer runs out. Extract and you keep it all; sell loot to the trader and buy better gear. Die and
you lose everything except your 2×2 secure pocket. Progress is saved in your browser.
The 0.5 guns update added aiming down sights, real view recoil, spread/flinch, a knife (backstabs kill),
crouching and stamina, and retuned time-to-kill. The 0.6 update made scavs and Raiders smarter (senses, paths
around buildings, patrols, cover, healing). The 0.7 multiplayer update (in progress) adds **ONLINE**: party up
with a friend's code and queue into raids with other players (2-6 per raid), and shoot each other, on a game
server on Heroku.
Every push to `main` builds the web version and publishes it to GitHub Pages.

**Controls:**

| Key | Action |
|---|---|
| Click | Play (captures the mouse) / shoot |
| Right-click (hold) | Aim down sights |
| Mouse | Look |
| WASD | Move |
| Shift | Sprint (forwards only, uses stamina) |
| Space | Jump |
| C | Crouch (toggle; slower and silent) |
| R | Reload (rotate an item while dragging it in the inventory) |
| V | Knife |
| 1 / 2 | Primary / secondary weapon |
| 3–6 | Hotbar items (heals bind automatically) |
| H | Heal (uses the best-fitting heal item) |
| F | Search / loot |
| Q / E | Lean left / right (hold; tap-to-toggle in the Esc menu) |
| Tab | Inventory |
| O | Show open extracts |
| Esc | Menu: volume, mouse sensitivity, damage numbers on/off |
| F3 | Debug overlay |

**Adding items:** edit `ITEMS` and `LOOT_TABLES` in `scripts/item_db.gd`, then run `python3 tools/gen_item_list.py` to update `docs/ITEMS.md`.

**Tuning:** most numbers (damage, fire rate, recoil, enemy speed…) are `@export` vars. Select the node in Godot and tweak them in the Inspector.

## Tests

CI runs `tests/smoke_test.gd` headless. It plays through the raid scene in named sections: shooting the dummy
(body + head), reloading, aiming, accuracy and recoil, time-to-kill numbers, a scav shooting you, the knife,
movement/crouch/stamina/jump, loot containers and character models, the grid inventory, equipment and the inventory
screen, healing, extracting, dying, the saved profile, the hideout (buy/sell/free kit) and settings.
It must print `SMOKE TEST: PASSED` with no `SCRIPT ERROR`. Run it locally from the repo root:

```
godot --headless --import
godot --headless --fixed-fps 60 -s tests/smoke_test.gd
```

`--fixed-fps 60` makes each frame exactly 1/60 s of game time, so the test is deterministic and takes a couple of
seconds instead of ~40. To run only some sections (plus the ones they depend on), add their names:
`godot --headless --fixed-fps 60 -s tests/smoke_test.gd -- section=knife,heal` (or set `SECTION=knife,heal`).
The section names are listed at the top of the test. Your saved profile is backed up and restored by the test.

Sounds in `audio/` are generated by `python3 tools/make_sounds.py`. Replace them with real ones any time.

## Versions

`MAJOR.PHASE.CHANGE`: each roadmap phase bumps the middle number, and every change after that bumps the last.
The current version is `config/version` in `project.godot`; it's shown in the menu and the top-right corner.
See [`CHANGELOG.md`](CHANGELOG.md) for what changed in each version.

## Running it locally

1. Download **Godot 4.5** (standard version, *not* .NET) from https://godotengine.org/download
2. Open Godot → **Import** → pick this folder's `project.godot`
3. Press **F5** (or the ▶ button in the top right)

## One-time setup: playable web link

In this repo on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
After that, each push to `main` deploys to https://tavishhanda.github.io/Bloxov/ (capital B: Pages URLs are case-sensitive).

## Coming from Unity

| Unity | Godot |
|---|---|
| GameObject + Components | **Node** (each node does one thing; build a tree of them) |
| Prefab | **Scene** (`.tscn`). Any scene can be instanced inside another |
| `MonoBehaviour` | Script attached to a node (`extends CharacterBody3D`) |
| `Start()` / `Update()` / `FixedUpdate()` | `_ready()` / `_process(delta)` / `_physics_process(delta)` |
| `[SerializeField]` | `@export` |
| `GetComponent<T>()` | `$ChildName` or `get_node("Path")` |
| `CharacterController` | `CharacterBody3D` + `move_and_slide()` |
| ProBuilder | **CSG nodes** (`CSGBox3D`, etc.) for gray-boxing |
| UnityEvents / C# events | **Signals** |
| Input Manager | Project Settings → **Input Map** |

## Layout

```
scenes/     .tscn scenes (hideout = main scene, raid level, player, scav/raider, containers, dummy)
scripts/    GDScript (player, gun, knife, scav AI, inventory, profile, hideout, HUD...)
assets/     imported models (.glb)
art_source/ Blender sources (ignored by Godot)
materials/  shared materials
audio/      sound effects
tests/      headless gameplay test
tools/      helper scripts
docs/       design and planning docs (see below)
```

`docs/`: `GAME_DESIGN.md` (the design), `ROADMAP.md` (milestones), `BACKLOG.md` (parked ideas),
`ITEMS.md` (every item and loot table; generated by `python3 tools/gen_item_list.py`), `INVENTORY_DESIGN.md`,
`STASH_TRADER_PLAN.md` and `GUNS_PLAN.md` (feature plans), `ART_SPEC.md` (art pipeline and sizes).
